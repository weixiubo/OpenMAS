# OpenAGORA experiments

This package provides EGOR evidence repair and stage execution, CAGO analysis,
and QA/GAIA analysis utilities. It includes the EGOR-v10 evidence records used
by `openagora reproduce`.

Install both packages through the repository's Python 3.11 uv workspace with
`uv sync --locked`. The workspace README describes supported stages, local
model configuration and the offline reproduction workflow.
